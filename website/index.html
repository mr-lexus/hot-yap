LOCAL ENGINE

Your audio can stay on your machine.

Run faster-whisper with CTranslate2 locally. Models are downloaded only when you choose one and reused by a persistent worker.

RU ↔ EN

Code switch without apology.

Prompt conditioning and careful term fixes help keep Python, Docker, useEffect, and GitHub in Latin script.

PUSH TO TALK

Hold. Speak. Let go.

A configurable global shortcut and always-on-top overlay make dictation fast without taking over your workflow.

MODEL CONTROL

Tiny to large-v3. CPU to CUDA.

Pick a compatible CTranslate2 model, manage downloads in the app, and fall back to CPU if CUDA is unavailable.

CLIPBOARD FIRST

No haunted auto-typing.

HotYap never simulates keystrokes. It copies UTF-8 text; you paste only when and where you mean to.

OPTIONAL CLOUD

Local by default. APIs by choice.

Use supported speech providers or text post-processing only when you explicitly configure them. Keys stay in the OS credential store.
