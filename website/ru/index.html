Маленькая программа. Неприлично громкий лай.

Для фразы, которую другая диктовка опять изуродовала.

LOCAL ENGINE

Аудио может остаться на вашем компьютере.

Запускайте faster-whisper с CTranslate2 локально. Модель загружается только по вашему выбору и повторно используется постоянным worker-процессом.

RU ↔ EN

Переключайте язык без извинений.

Промпт и аккуратные исправления помогают оставить Python, Docker, useEffect и GitHub в латинице.

PUSH TO TALK

Зажали. Сказали. Отпустили.

Настраиваемый хоткей и компактный оверлей ускоряют диктовку, не захватывая ваш рабочий процесс.

MODEL CONTROL

От tiny до large-v3. От CPU до CUDA.

Выбирайте CTranslate2-модель, управляйте загрузками и спокойно откатывайтесь на CPU, если CUDA недоступна.

CLIPBOARD FIRST

Никакой одержимой автопечати.

Горячий Лай не симулирует нажатия. Он копирует UTF-8-текст, а вставляете его вы сами.

OPTIONAL CLOUD

Локально по умолчанию. API по желанию.

Подключайте речевые API или постобработку только явно. Ключи хранятся в системном хранилище учётных данных.
